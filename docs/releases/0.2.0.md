# 0.2.0

## 中文

**在笔记里直接工作**
选中文字即可改写、总结或解释；结果先预览，再选择替换选区或插入下方，不点确认不会写入。

**改完能审阅、能撤销**
每次运行结束列出改动的 Markdown 文件与 diff；可撤销单个文件或全部，不需要 git。

**运行历史可审计**
历史记录包含状态、模型/权限、工具调用、耗时、改动文件与错误；支持按标题/备注和 7/30 天筛选，一键复制摘要。

**批量处理多篇笔记**
一次选择多篇笔记，按顺序执行同一指令；逐项显示状态，可随时取消，单项失败不终止整批；整批结束统一审阅/撤销。

**运行更可靠**
显式运行状态机与主链路测试；准备失败、取消、超时都会正确收尾，不再卡在“停止”按钮。

## English

**Work inside the note**
Select text to rewrite, summarize, or explain. Preview the result, then replace the selection or insert it below — nothing is written until you confirm.

**Review and undo changes**
After each run, see the Markdown files that changed and a diff. Undo one file or the whole run; no git required.

**Auditable run history**
History records status, model/permission, tool calls, duration, changed files, and errors. Filter by title/note and 7/30 days, and copy a summary.

**Batch across notes**
Pick multiple notes and run one instruction sequentially. Per-item status, cancel anytime, failures don't stop the batch, and one review/undo at the end.

**More reliable runs**
An explicit run state machine and main-chain tests; prepare failures, cancels, and timeouts settle correctly instead of leaving the Stop button stuck.
