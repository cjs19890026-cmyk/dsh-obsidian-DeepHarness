# 0.2.0

0.2.0 把 DeepHarness 从“能跑的聊天面板”推进到可信的笔记工作流：选中文字即可改写、总结或解释，结果先预览再应用；每次运行后可审阅 diff 并撤销；历史记录可审计；多选笔记可批量处理；恢复会话不再丢上下文。

建议所有 0.1.x 用户升级。

---

## English

0.2.0 turns DeepHarness from a chat panel into a trustworthy note workflow: rewrite, summarize, or explain a selection with preview-before-apply; review and undo changed files after each run; inspect auditable history; batch-process selected notes; and resume sessions without losing context.

Recommended for all 0.1.x users.
